What It Does

点、找、填、导、整，这些活它都能接

不是只会聊天。Aaim 能直接操作你正在用的软件，把大部分需要手工点击的步骤接过去。

命令与脚本

批量处理、格式转换、日志排查，直接执行命令，不用你一条条敲。

Excel 与报表

汇总、清洗、透视、画图，按你的口径直接出结果，不用一格一格复制粘贴。

Word 与 PPT

批量替换、统一格式、生成初稿，改完直接交付，不怕文件多。

浏览器

查资料、比价格、填表单，把网页上的数据整理成表，省掉来回切换。

文件与文件夹

批量重命名、按规则归档、查找、转换格式，几分钟的活交给它。

桌面软件

打开应用、点按钮、填表单、导出数据，像人一样操作，不需要软件提供接口。

Control

四层控制，总有一层能落到实处

MCP + Shell + GUI + API 协同：同一件事的四条路径，能调就调，能点就点。

01 · MCP

接入工具

把标准工具和外部服务接进来，需要什么能力就扩展什么。

02 · SHELL

命令与脚本

在 Linux 上这是最顺手的一层：批处理、转换、巡检都交给命令。

03 · GUI

像人一样点

看屏幕、点按钮、填表单，能用鼠标的软件都能操作。

04 · API

系统与接口

调用接口、读写数据，把几个系统串成一条流程。

该用哪层，由 Aaim 自己判断。一层走不通，就换一层。

Privacy

你的工作，
留在你的电脑里

配置、历史、记忆、日程和 Key 都保存在本机 ~/.aaim。只有你发起任务时，完成任务所需的内容才会发给你选择的模型。

接口也可以换成你自己的模型服务——隐私的边界，由你决定。

1
下载 deb

打开上面的蓝奏云链接，提取码 hqb2，下载 aaim_1.3.4_amd64.deb。

2
安装

进入下载目录执行 sudo apt install ./aaim_1.3.4_amd64.deb，或在文件管理器里双击。

3
打开、填 Key

从应用菜单打开 Aaim（也可以在终端敲 aaim），在设置里填接口地址和 API Key。

卸载：sudo apt remove aaim。用户数据在 ~/.aaim，卸载不会删，需要清空就手动删掉这个目录。
